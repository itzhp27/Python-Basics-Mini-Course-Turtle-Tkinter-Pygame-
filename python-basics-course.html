01
TURTLE

Draw with code

Before graphics or game logic, every programmer starts with the same three ideas: variables, loops, and functions. This lesson teaches them the most visual way possible — by steering a turtle around the screen until it draws something.

What you'll learn

  • Variables and basic data types
  • for loops that repeat an action
  • Writing your own functions

Example: a colored square

lesson1_turtle.py
import turtle

artist = turtle.Turtle()
colors = ["red", "orange", "yellow", "green"]

for i in range(4):
    artist.color(colors[i])
    artist.forward(100)
    artist.left(90)

turtle.done()

Try it yourself

  1. Change the loop so it draws a triangle, then a hexagon.
  2. Write a function draw_shape(sides, length) that can draw any polygon.
  3. Challenge: make the turtle draw a spiral by increasing the forward distance a little on every pass through the loop.

02
TKINTER

Build a window people can click

A program that only runs top-to-bottom in a terminal feels abstract. Tkinter changes that by giving code a window, a label, and a button. This lesson is about event-driven thinking: code that waits for you to act.

What you'll learn

  • Creating windows, labels, and buttons
  • Connecting a button to a function
  • Keeping track of state while the program runs

Example: a click counter

lesson2_tkinter.py
import tkinter as tk

def add_click():
    global count
    count += 1
    label.config(text=f"Clicks: {count}")

count = 0
window = tk.Tk()
window.title("Click Counter")

label = tk.Label(window, text="Clicks: 0", font=("Arial", 20))
label.pack(pady=20)

button = tk.Button(window, text="Click me", command=add_click)
button.pack(pady=10)

window.mainloop()

Try it yourself

  1. Add a "Reset" button that sets the count back to zero.
  2. Add a second label that shows "Even" or "Odd" based on the current count.
  3. Challenge: turn this into a tip calculator with an entry box for the bill and a button that shows a 15% tip.

03
PYGAME

Turn your code into a game

Pygame brings the first two lessons together — drawing and interactivity — inside a loop that runs 60 times a second. By the end of this lesson, students have a square they can drive around the screen with the arrow keys.

What you'll learn

  • The game loop: update, draw, repeat
  • Reading keyboard input every frame
  • Basic boundary and collision checks

Example: a square you can drive

lesson3_pygame.py
import pygame

pygame.init()
screen = pygame.display.set_mode((400, 400))
clock = pygame.time.Clock()
x, y = 180, 180

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        x -= 4
    if keys[pygame.K_RIGHT]:
        x += 4

    screen.fill((20, 20, 20))
    pygame.draw.rect(screen, (255, 90, 0), (x, y, 40, 40))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Try it yourself

  1. Add up and down movement with the up and down arrow keys.
  2. Make the square bounce off the edge of the screen instead of leaving it.
  3. Challenge: add a second rectangle and detect when the two overlap.
